# 创作与增长 · 五库闭环
2026-11-06。用户：Jocelyn；目标：更稳定产出、及时复盘、用证据优化选题排期，提高增长效率。

沿用本地 Python + 原生网页，主账号小红书。用户确认每周3篇、180分钟；目标粉丝和截止日期沿用现有记录，不替用户确认。

## 需求与验收
- REQ-001 五库：展示来源时间、真实选题、范文、规则和复盘；模板示例隔离；失联保留最后成功快照并显示错误。
- REQ-002 选题：按用户可调的适配/价值/素材准备度评分，展示评分公式。未评分无预测；点击选题可带入排期与Skill任务包。
- REQ-003 排期：周视图显示草案/确认/完成与时间预算；超180分钟提示，超3个生产任务提示；每日最多一项确认任务。确认前不算已安排；完成不等于发布。
- REQ-004 Skill：选题、标题、初稿、终检、复盘任务包注入真实五库上下文；显示具体技能、引用、假设；可复制到Codex执行，也可用户主动调用现有LLM。无自动收费调用，不伪称已执行本地skill。
- REQ-005 复盘：登记实际发布日期，产生24h/7d回填提醒；迟录不能伪标标准时间点。指标缺失不填0，零分母不算率；同一口径最新快照对比。
- REQ-006 实验：记录假设、单个变量、观察与下一步；结论默认待验证，不能自动成为已验证规则；可带入下一轮任务包。

不做：自动发布、自动评论私信、跨账号比较、承诺涨粉、自动改飞书规则置信度、无限制AI批处理。
成本：新增本地逻辑不引入依赖；LLM沿用现有配置，用户点击才调用，实际费用取决于模型，不估造固定金额。
成功指标：本周确认/完成任务、发布篇数、回填完成度、同口径新增关注及转粉率。当前历史数据不能证明因果。

REQ-007：可切换上一周/下一周，显示所选周的确认工时；点击排期的AI任务包携带对应选题、上下文与Skill分工，且不会自动调用付费API。2026-11-06验收：下周3项、180分钟，任务包携带来源记录ID与标题Skill。
