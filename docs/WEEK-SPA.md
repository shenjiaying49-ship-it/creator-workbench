# 周排期 SPA（用户最新需求）
首页改为周一至周日的周视图，每天显示备稿检查、已确认创作任务、用户自建任务和周复盘入口。建议不自动等于已确认发布。点击标题进入独立编辑视图，返回保留周位置。数据与复盘合成一个视图：账号快照、分观察口径的单篇数据、复盘结论、下一步。原历史数据只读保留，不混用未知与0、不跨平台求和。

路由：同一index应用 #/week?start=YYYY-MM-DD、#/edit?day=...&topic=...、#/review。顶部仅周排期/数据与复盘；编辑视图有返回周排期。支持前进后退、深链接刷新、离开前未保存确认。旧daily/studio/analytics/secondary-board链接由服务器跳转对应hash路由；旧页面文件作为恢复备份，不再是导航入口。

数据：workspace_app.py 聚合飞书确认日期和daily_creations生成稿；排期关联旧Coffee Chat稿也可编辑，本地覆盖保留原飞书内容。任务完成独立记录不表示已发布。新复盘保存结构化指标与下一步，兼容现有growth快照/指标及飞书复盘。锁与版本检查防覆盖。旧analytics历史明确标口径不齐只读，不参与汇总。

UI：沿用浅绿纸面；周视图桌面7列，手机按日纵排；统一应用shell和状态条；编辑保留已有Skill证据，数据页集中表单和记录。加载/空/错误明确，无iframe。

串行验收：聚合/去重/版本保护单测→SPA路由和编辑接入→浏览器周切换/标题编辑/返回/历史/复盘/手机→回归与部署。默认沿用已确认4篇180分钟，不重排、不新造发布计划。每天“查看建议稿”和周日复盘为明确标识的建议。
