# 大号自媒体工作台

把 Jocelyn 大号的小红书创作流程封装成的本地网页应用：素材箱 → 创作流程 → 稿件库 → 排期看板 → 数据分析。

## 启动

```bash
python3 server.py
# 或双击 启动.command
```

打开 http://127.0.0.1:8501

> 首次使用：`cp config.example.json config.json`，把 `llm.api_key` 换成你自己的 key（`config.json` 与 `data/` 均不入库）。

- 主工作台：`/index.html`
- 数据分析：`/analytics.html`

## 功能

### 1. 素材箱
- 粘贴参考材料（对标笔记、X 帖子转述、商单 brief 文本）
- 上传 PDF / 图片 / markdown 文件
- 勾选「本篇使用」的素材会自动带入 AI 生成上下文

### 2. 创作流程（四步）
- Step 1 选题角度：AI 生成 3 个切入角度 + 内容线判断
- Step 2 标题候选：按标题方法论出 5 个候选，点击选定
- Step 3 正文初稿：基于素材 + 标题生成，严格 1000 字以内
- Step 4 精修定稿：手动编辑或输入意见让 AI 打磨，实时字数统计

商单模式：勾选后自动启用「不说满」规则（技术表述留余地、附品牌确认清单）。

### 3. 稿件库
状态流转：素材 → 草稿 → 待确认 → 已发布。已发布稿件可一键跳数据分析页补录数据。

### 4. 数据分析（独立页面）
- 录入每篇笔记 24h / 7 天的观看、赞、藏、评、分享、涨粉、主页访问
- 概览卡 / 发布趋势图 / 转化漏斗 / 内容线对比 / 单篇表现表（可排序）
- 多账号切换（Jocelyn / Yuki.AI）

## AI 生成配置

编辑 `config.json`：

```json
{
  "llm": {
    "base_url": "https://openrouter.ai/api/v1/chat/completions",
    "api_key": "你的 key",
    "model": "anthropic/claude-sonnet-4"
  }
}
```

兼容任何 OpenAI 格式的接口。未配置 API Key 时，素材箱、稿件库、数据分析均可正常使用，只有 AI 生成按钮会报错提示。

## 每日发稿台（/daily.html）

五库系统的每日驾驶舱：今天发什么，已经替你排好了。

- **一稿多用引擎**（2026-10-30 定稿，知乎线已移除）：每周 3 条核心稿，小红书首发（周二干货 / 周四复盘 / 周六攻略，按 ISO 周从核心稿池轮换），自动拆发平台版本——周一 = 周六稿的抖音口播版、周三 = 周二稿的抖音口播版（40 分钟：回读源稿 5 / 写 200-300 字 20 / 实拍粗剪 15）、周五 = 周四稿的 Threads+X 海外版（20 分钟轻量）。改写日不写新稿，只按目标平台风格 skill 换挡。周日公众号固定复盘栏目 + 30 分钟提炼。每周节奏：小红书×3 + 抖音×2 + Threads/X×1 + 公众号×1。；自带开头第一句、自动套用的规则库规则、40 分钟拆解（5 拉框架 / 25 写完 / 10 活人感三问）和「我发布好了」打卡。
- **每天三件小事**：收集 10 分钟、评论 5 条（每天 1 块钱）、数据回填 5 分钟。
- **本周排期**：七天日卡 + 池子下一批；周日自动固定「周复盘」栏目（记忆锚点）。
- **Skill 进化**：五库循环图、进化日志、四平台风格基因（viral-style-gene 注入）、规则库按置信度筛选、周日提炼提示词（可复制）。
- **五库流水**：选题/范文/作品/规则/复盘五库水位与作品数据表。
- 打卡状态存浏览器 localStorage（key `wuku_daily`），按天滚动。

数据当前为 2026-10-29 从豆包多维表格《自媒体五库系统》导出的快照（选题 21/范文 29/作品 7/规则 21/复盘 5）。接实时数据：把五张表每日导出为 `static/wuku-data.json` 并放开 daily.html 底部的 fetch 注释块。

## 自动化管道（2026-10-30 新增）

- **素材库实时同步**（`com.wuku.sync`，每 30 分钟 + 开机登录）：`tools/wuku_sync.py` 拉豆包五张表 → `static/wuku-data.json`；daily.html 每次打开自动读取，五库流水/规则库/作品表/进化日志实时刷新。
- **AI 初稿**（`/api/wuku/draft`）：daily.html 每天自动按当天选题生成初稿——提示词注入三套已验证平台风格 skill（Threads/小红书/口播，来自规则库）+ 本人发过的爆款标题作风格参考。事实红线：选题理由之外的具体经历一律 `[待填：…]` 占位，禁止编造。按「日期+槽位」缓存于 `data/wuku_drafts.json`，页面可「重新生成」。
- **每周自动提炼**（`com.wuku.distill`，周日 20:30）：`tools/wuku_distill.py` 取近 8 天「待分析」范文 + 作品数据 → LLM 提炼 ≤5 条规则 → 回写豆包规则库（一律「待验证」，等作品数据验证）→ 范文标记「已提炼」。`--dry-run` 只看不写。
- **AI 发布前终检**（`/api/wuku/check`，2026-10-31）：初稿生成后自动跑，替代手动活人感三问。清单已内化：活人感（[待填] 残留/专属细节）、标题锚点+≤20 字+A/B 备选、30 字出钩、判断句与金句、**主页转粉钩子**（主页转粉率规则）、提问式互动、黑名单词、**黄金发布时间表给当天时段建议**（后两项来自 GitHub 起号攻略）。输出 ✓/✗ + 具体改法 + 可发/改后发。
- **数据快速回填**（`/api/wuku/backfill` POST {text}）：页面「贴数据 30 秒回填」——把创作者中心的数据文字（或一句话 shorthand）贴进去，LLM 解析 → 按标题匹配作品库记录更新，无匹配则新建。
- **初稿吃真实范文（2026-11-01）**：`wuku_sync.py` 导出范文库真实条目全文摘录（fanwen_list）；`/api/wuku/draft` 按选题相关性挑 3 篇同类范文（钩子/结构/节奏）注入提示词。`tools/wuku_distill.py --backlog` 支持全量积压提炼（已跑 3 批，30 条待分析全部消化，+15 条待验证规则入库）。
- **复盘口径（用户拍板）**：复盘=生活故事（事件→转折→我学到的→可抄动作），不发后台数据复盘——周日公众号栏目已改为「本周踩坑复盘」。
- **数据看板**（`/wuku-stats.html`）：真实作品数据汇总（快照 KPI + 回填记录 + 全部作品按赞排序）。回填三路：页面贴文本 / 截图发 ZCode 助手识别 / POST metrics 直灌。
